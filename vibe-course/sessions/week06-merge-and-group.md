# Week 6：合并、分组与迷你项目

> 总时长：180 分钟（3 节 × 60 分钟）
> 数据：`data/air_quality_simple.csv`、`data/city_info.csv`
> 关键概念：`merge`、`concat`、`on` / `how`、`groupby`、`agg`、人口加权指标、可复现迷你报告

## 本节结束后学生能做到

- 用 `merge` 把两张表按城市合并，并检查匹配情况。
- 用 `groupby` + `agg` 做多指标汇总。
- 计算人均 / 人口加权指标，理解为什么原始均值可能有偏差。
- 用 DSH 拆解并完成一个 120 字以内的迷你项目。

## 课前准备

- 检查两个 CSV 的城市字段是否大小写一致。
- 提醒：`merge` 后如果匹配行变少，要先看 `how` 和键值。

## 第 1 节：merge 与 concat（60 分钟）

### 目标

掌握横向合并与纵向拼接的区别，并会检查合并质量。

### 教师演示（10 分钟）

让 DSH 完成第一次合并：

```text
请读取 data/air_quality_simple.csv 和 data/city_info.csv。
按 city 合并，输出：
1. 合并后 shape；
2. 哪些城市在空气表中有、在 city_info 中不存在；
3. 哪些城市在 city_info 中有、在空气表中不存在；
4. 合并后是否有空值。
```

### 学生练习（35 分钟）

1. 运行上面的审计。
2. 尝试 `how="inner"`、`how="left"`、`how="outer"` 三种合并，记录行数差异。
3. 用一个 `merge` 后的表完成：
   - 每个城市的 `PM25 / population_million` 人均污染强度；
   - 按 `region` 汇总平均 PM25 和平均人口。
4. 让 DSH 解释：为什么匹配不上的城市必须报告，而不是悄悄丢弃？

### 复盘（15 分钟）

- 合并前先检查键的类型和唯一性。
- 合并后的空值常常是“数据源不完整”，不是 pandas 的错。

### 本节关键提示词

```text
请审计 air_quality_simple.csv 与 city_info.csv 的合并：
输出三种 how 的行数、未匹配城市列表、合并后空值。
然后解释哪种 how 更适合“分析所有有空气质量数据的城市”。
```

## 第 2 节：groupby 与多指标汇总（60 分钟）

### 目标

掌握 `groupby` + `agg` 一次输出多个指标，并理解加权均值。

### 教师演示（10 分钟）

```text
请基于合并后的数据，按 region 汇总：
- 城市数量；
- 平均 PM25；
- 最大 PM25；
- 总人口；
- 人口加权平均 PM25 = sum(PM25 * population) / sum(population)。
```

### 学生练习（35 分钟）

1. 运行上面的代码，比较“平均 PM25”和“人口加权平均 PM25”的差异。
2. 用中文解释：如果一个高污染城市人口很少，两种均值会怎样？
3. 让 DSH 生成一个 `region_summary.csv` 并保存到 output。
4. 自己再新增一个指标：`PM25 / area_km2` 并解释它代表什么。

### 复盘（15 分钟）

- 指标定义会影响结论。报告里必须写清楚“是简单平均还是人口加权”。
- AI 可以帮你算，但不能替你决定“哪个指标更符合业务问题”。

### 本节关键提示词

```text
请基于 air_quality_simple.csv 与 city_info.csv 的合并结果：
按 region 输出城市数、平均 PM25、人口加权平均 PM25、最大 PM25、总人口，
保存为 output/region_summary.csv，并解释两种平均为什么可能不同。
```

## 第 3 节：Mini project：120 字迷你报告（60 分钟）

### 目标

完成“提出问题 → 合并数据 → 分析 → 图表 → 结论”的最小闭环。

### 任务（任选一题）

1. 华南和华北谁的人均 PM25 强度更高？
2. 高污染城市是否集中在人口更密集的省份？
3. 城市面积和 PM25 是否有明显关系？

### 学生练习（35 分钟）

1. 用 plan mode 让 DSH 先给方案，不直接写代码：
   ```text
   /plan 我要回答：<你的问题>。
   请先调查数据字段，给出：指标定义、合并方式、统计方法、图表类型、验收标准。
   ```
2. 确认方案后，让 DSH 生成代码，运行并检查。
3. 输出：
   - 1 张图；
   - 120 字以内结论；
   - 1 条局限。
4. 保存到 `projects/<姓名>/mini_project/`。

### 复盘（15 分钟）

- 展示时按“问题 → 口径 → 结果 → 局限”讲，不念代码。
- 老师检查每个结论是否能指出数据依据。

### 作业

提交 mini project，要求包含：`README.md`、`scripts/`、`output/`，README 里写清楚数据来源、指标定义和 3 个步骤。
