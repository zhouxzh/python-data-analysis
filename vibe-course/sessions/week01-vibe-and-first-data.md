## 第 1 节：数据分析与 AI 时代的工作方式（60 分钟）

### 目标

理解为什么“会用 AI 写代码”不等于“会做数据分析”，认识 DSH 能做什么、不能做什么。

### 教师演示（10 分钟）

1. 打开 DSH Web GUI，把工作区切到本仓库。
2. 直接输入一句话：
   ```text
   请读取 data/成绩单.xlsx，先不要修改文件，输出行数、列名、每列缺失数和前 5 行。
   ```
3. 对照 DSH 输出解释：`shape`、`dtypes`、缺失值、数据行。

### 学生练习（35 分钟）

1. 创建 `projects/<姓名>/raw`、`scripts`、`output` 三个目录。
2. 让 DSH 读取 `data/成绩单.xlsx`，要求只输出：
   - 行数和列数；
   - 每列类型；
   - 是否存在缺失；
   - 前 3 行。
3. 把 DSH 的回答抄进自己的 notebook，并用一句中文解释“这份数据能不能直接回答平均分问题”。
4. 再问 DSH 一次：“如果把成绩表的平均分算错，可能是什么原因？” 对比 DSH 的回答和自己想到的答案。

### 复盘（15 分钟）

- 每个学生说出 1 个 DSH 输出中有价值的信息。
- 老师总结：AI 能读数据，但“哪个问题值得回答”和“结果可不可信”必须由人判断。

### 本节关键提示词

```text
请读取 data/成绩单.xlsx，不要修改文件。
输出：
1. 行数和列数；
2. 每列类型；
3. 每列缺失数；
4. 前 3 行。
```

## 第 2 节：Python 最基础的类型与结构（60 分钟）

### 目标

掌握变量、`int` / `float` / `str` / `list` / `dict`、`print`、简单 `for` 循环和 `import`，并理解“代码是给 AI 和人都能看的过程记录”。

### 教师演示（10 分钟）

让 DSH 生成并运行以下最小示例：

```text
请运行这段 Python 并解释每一行：
scores = [85, 92, 78, 90, 88]
total = 0
for s in scores:
    total = total + s
print(total / len(scores))
```

### 学生练习（35 分钟）

1. 用 `dict` 保存 3 名同学的成绩：
   ```python
   students = [
       {"name": "张三", "score": 85},
       {"name": "李四", "score": 92},
       {"name": "王五", "score": 78},
   ]
   ```
2. 让 DSH 生成代码，输出每个人的名字和是否及格（≥60）。
3. 自己把 `total = total + s` 改成 `total += s`，看是否仍然运行。
4. 故意制造一个错误（例如把 `scores` 写成 `score`），把真实报错粘贴给 DSH，要求解释。

### 复盘（15 分钟）

讨论：
- 为什么 AI 时代还要能读懂 `for` 循环？
- 报错信息是“给 AI 的重要上下文”，不是失败记录。

### 本节关键提示词

```text
请生成并运行一段 Python 代码：
用 list 保存 5 名同学的成绩，用 for 循环计算总分和平均分，
再用 dict 保存每位同学是否及格。
要求代码可读，并用中文注释解释关键步骤。
```

## 第 3 节：Mini case：统计成绩表（60 分钟）

### 目标

完成第一次完整 vibe loop，产出一个可以运行、可以导出的 notebook。

### 任务

使用 `data/成绩单.xlsx`，回答：

1. 三门课的平均分分别是多少？
2. 每位同学的总分排名是什么？
3. 哪一门课的同学成绩差异最大？

### 学生练习（35 分钟）

1. 在 DSH 中输入以下提示词，要求“先给方案，不写完整代码”：
   ```text
   我要用 data/成绩单.xlsx 回答 3 个问题：
   三门课平均分、学生总分排名、哪门课差异最大。
   先告诉我：
   1. 需要哪几列；
   2. 分别用什么统计量；
   3. 我该如何验证结果。
   ```
2. 确认方案后，要求 DSH 生成“最小可运行 pandas 代码”，并保存为 `projects/<姓名>/scripts/first_analysis.py`。
3. 运行代码，检查输出：
   - 平均分是否合理；
   - 排名有没有并列；
   - 差异最大用什么指标定义（极差？标准差？）是否一致。
4. 把结果整理进 Jupyter notebook，导出 HTML 或 PDF。

### 复盘（15 分钟）

- 每个学生展示 1 个“我让 DSH 改过的地方”。
- 老师给出第一周检查清单：数据被读、代码可运行、结果可解释、原始文件未改。

### 作业

用 DSH 生成代码，统计 `data/成绩单.xlsx`，然后写出 3 个“从这份成绩单能回答、但第一版提示词没有回答”的问题。

## 评分要点

| 项目 | 要求 |

| 运行 | notebook 自上而下可执行 |
| 过程 | 保留至少 1 次报错或修改记录 |
| 结果 | 3 个统计结果都有代码和输出 |
| 验证 | 能说出每个结果对应的字段和计算方法 |
