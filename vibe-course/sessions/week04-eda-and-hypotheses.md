## 第 1 节：描述统计与相关性（60 分钟）

### 目标

掌握描述统计，并理解“相关不等于因果”。

### 教师演示（10 分钟）

让 DSH 读取银行营销数据并做初步统计：

```text
请解压 data/bank_marketing.zip 并读取其中的 CSV（分号分隔）。
输出：
1. shape、列名、dtypes；
2. 数值列 describe；
3. y 的 value_counts(normalize=True)；
4. 哪些类别列包含 unknown，比例是多少。
不要修改原文件。
```

### 学生练习（35 分钟）

1. 运行上面的审计，记录：
   - 总行数；
   - `y=yes` 比例；
   - `unknown` 最高的 3 列。
2. 让 DSH 解释：为什么 `y` 比例不是 50% 时，只看准确率很危险？
3. 用 `data/air_quality_simple.csv` 做一次简单相关分析：
   ```python
   df[["PM25", "PM10", "NO2", "SO2"]].corr()
   ```
4. 讨论：PM25 和 PM10 相关高，能说明它们互相导致吗？

### 复盘（15 分钟）

- 统计摘要只描述“是什么”，不解释“为什么”。
- 发现 `unknown` 之后，下一步不是直接填缺失，而是先判断它代表“没记录”还是“业务上确实不知道”。

### 本节关键提示词

```text
请基于银行营销数据输出一个“数据审计摘要”：
shape、dtypes、缺失、unknown 比例、y 分布、数值列相关性。
重点提醒我哪些字段可能存在目标泄漏风险。
```

## 第 2 节：带着问题做 EDA（60 分钟）

### 目标

学会“每个分析问题对应一个计算和一个图表”，并能继续追问。

### 教师演示（10 分钟）

让学生明确问题，而不是说“做 EDA”：

```text
我要回答 3 个问题：
1. 不同 contact 方式的订阅率是否不同？
2. 哪几个月的订阅率更高？
3. 之前联系过且成功过的客户，订阅率是否更高？
请为每个问题输出：分组统计表 + 一张图 + 50 字结论 + 样本量提醒。
```

### 学生练习（35 分钟）

1. 完成上述 3 个问题。
2. 针对第 3 个问题，要求 DSH 输出“之前联系过但失败”和“从没联系过”的对比，而不是只输出“成功过”的分组。
3. 检查每个结论是否都写了样本量。
4. 自己再提出 1 个可以继续追问的问题。

### 复盘（15 分钟）

- 好的 EDA 是“从结果反推问题”，不是图越多越好。
- 分组差异大，可能来自样本量、选择偏差或字段口径，先列出替代解释。

### 本节关键提示词

```text
基于银行营销数据回答 3 个问题：
contact、month、poutcome 与订阅率的关系。
每个问题输出：统计表、图、结论、样本量、风险提醒。
不要使用 duration 作为前置变量来解释订阅率。
```

## 第 3 节：Mini case：3 个发现 + 3 个假设（60 分钟）

### 目标

把 EDA 结果组织成“已验证发现”和“待验证假设”。

### 任务

1. 完成以下分组分析：
   - `contact` × 订阅率；
   - `month` × 订阅率；
   - `poutcome` × 订阅率；
   - `campaign` 分桶 × 订阅率。
2. 输出 3 个“已经有数据支持的发现”。
3. 输出 3 个“需要更多数据或实验验证的假设”。
4. 让 DSH 检查是否误用了 `duration`。

### 学生练习（35 分钟）

示例结论模板：

```text
发现 1：cellular 联系方式的订阅率高于 telephone，样本量分别为 X 和 Y。
发现 2：3 月订阅率最高，但该月样本量只有 Z，需谨慎。
假设 1：订阅率差异可能与季节有关，而不是 contact 本身。
假设 2：之前联系过且成功的人更容易订阅，可能因为客户已有意向。
```

### 复盘（15 分钟）

- 每一条发现必须能指出“哪个字段、什么计算、多少样本”。
- 每一条假设必须写出“需要什么额外数据或实验才能验证”。

### 作业

把 3 个发现 + 3 个假设写成 `projects/<姓名>/output/eda_findings.md`，并让 DSH 做一次“反方审查”：尝试推翻你的每个结论。

## 评分要点

| 项目 | 要求 |
|---|---|
| 问题 | 每个分析都有明确问题 |
| 统计 | 分组表包含样本量和比例 |
| 风险 | 能识别 unknown、不平衡、duration 泄漏 |
| 表达 | 区分已验证发现与待验证假设 |
