# Week 5：可视化表达

> 总时长：180 分钟（3 节 × 60 分钟）
> 数据：`data/synthetic_air_quality.csv`、`data/air_quality_simple.csv`
> 关键概念：折线图、柱状图、直方图、散点图、子图、seaborn 分组比较、图表四要素、防误导

## 本节结束后学生能做到

- 每张图对应一个明确问题。
- 用 matplotlib / seaborn 生成趋势、比较、分布、关系四类图。
- 让 DSH 审查图表是否完整、是否误导。
- 用真实输出迭代修改图表，而不是直接相信 AI 生成的第一版。

## 课前准备

- 确认 `matplotlib` / `seaborn` 已安装。
- 提醒学生保存图时写明数据来源和口径。

## 第 1 节：一张图回答一个问题（60 分钟）

### 目标

掌握四种基础图，并知道“先有问题，再选图”。

### 教师演示（10 分钟）

让 DSH 生成一段可运行代码：

```text
请基于 data/air_quality_simple.csv 生成 4 张图：
1. 折线图：每个城市的 PM25 随时间或按行号变化；
2. 柱状图：城市平均 PM25；
3. 直方图：PM25 的分布；
4. 散点图：PM25 与 PM10 的关系。
每张图都要有标题、轴标签、数据来源；用 matplotlib + seaborn 完成。
```

### 学生练习（35 分钟）

1. 运行代码，观察每张图。
2. 回答：
   - 柱状图最适合比较还是展示趋势？
   - 散点图最能回答什么问题？
   - 直方图能直接比较两个城市吗？
3. 让 DSH 把柱状图按城市平均 PM25 降序排列。
4. 把图保存为 `projects/<姓名>/output/basic_plots.png`。

### 复盘（15 分钟）

- 图的“信息完整性”比美观更重要。
- AI 生成的图如果缺少单位或样本量，不能算完成。

### 本节关键提示词

```text
请审查我的绘图代码：
projects/<姓名>/scripts/basic_plots.py
检查每张图是否对应明确问题，标题/轴标签/图例/数据来源是否完整，
坐标轴是否被无意义截断，比例图是否写了样本量。
给出修改建议和修改后的代码。
```

## 第 2 节：seaborn 分组比较与面板（60 分钟）

### 目标

用 seaborn 快速比较分组分布，用 `subplots` 组成监测面板。

### 教师演示（10 分钟）

使用小时级数据：

```text
请读取 data/synthetic_air_quality.csv（datetime 列转 datetime）。
按城市分组：
1. 每个城市画一条 PM25 日平均折线；
2. 用 boxplot 比较三个城市的 PM25 分布；
3. 用 scatter 画 humidity 与 pm25 的关系；
4. 输出 2×2 子图面板并保存。
```

### 学生练习（35 分钟）

1. 运行上面的面板，检查三个城市是否清晰可区分。
2. 在 DSH 生成的代码上增加“样本量”标注：每个城市有多少小时记录。
3. 让 DSH 解释：箱线图比柱状图多提供了哪些信息？
4. 保存为 `projects/<姓名>/output/dashboard.png`。

### 复盘（15 分钟）

- 面板不是把图随便堆在一起，而是让读者一眼看到“趋势、分布、关系”。
- 如果图例颜色相近，信息会丢失；颜色选择要能区分。

### 本节关键提示词

```text
请生成一个 2×2 空气监测面板：
左上：三城市 PM25 日平均趋势；
右上：三城市 PM25 箱线图；
左下：humidity 与 pm25 散点；
右下：precipitation 与 pm25 散点。
每张图包含标题、轴标签、数据来源、样本量；保存为 output/dashboard.png。
```

## 第 3 节：Mini case：图表审查与迭代（60 分钟）

### 目标

学会把自己当成图表审查者，要求 DSH 帮忙找问题，而不是直接要“更漂亮的图”。

### 任务

1. 使用 Week 4 的银行营销数据或 `data/air_quality_simple.csv` 制作一张“对比图”。
2. 图必须包含：标题、轴标签、数据来源、样本量、单位。
3. 请邻座同学按下面清单审查：
   - 第一眼能否看懂比较对象？
   - 比例图是否写了样本量？
   - 坐标轴有没有误导？
   - 颜色是否可区分？
4. 把审查意见反馈给 DSH，生成第二版。

### 复盘（15 分钟）

- 好的可视化是“减少误解”，不是“增加装饰”。
- 最终交付时写 2 句解读：这张图支持什么结论、不能支持什么结论。

### 作业

制作一张信息完整、与业务问题对应的图，保存为 PNG，并写 2 句解读。

## 评分要点

| 项目 | 要求 |
|---|---|
| 问题对应 | 每张图都说明要回答的问题 |
| 信息完整 | 标题、轴标签、单位、数据来源、样本量 |
| 审查 | 至少有一次“AI 第一版 → 人工审查 → 修改” |
| 解读 | 结论不超过图能支持的范围 |
