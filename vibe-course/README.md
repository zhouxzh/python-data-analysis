# Vibe Programming × Python 数据分析（8 周 / 24 学时）

面向低基础学生的全新课程版本。旧版课程以“记住 pandas API”为主线，本课程改为“先问对问题，再让 DeepSeek Harness 生成第一版，人来验证、修正和做业务判断”。

课程时长：8 个晚上，每晚上 3 节课，每节 1 小时，共 24 学时。

课程目标：8 周后，学生能用自然语言指挥 DSH 完成一个真实的小型数据分析项目：拿到数据 → 审计清洗 → EDA → 可视化 → 简单模型 → 报告与展示，并能解释每一步为什么这么做。

## 为什么改用 Vibe Programming

- 数据分析的真正门槛不是“记住 pandas 语法”，而是定义问题、识别口径、验证结果和解释结论。
- AI 能快速生成第一版代码、图表和文字，但会把错误的业务假设也一起写出来。
- 因此学生的核心能力变成：`提问 → 要求最小可运行版本 → 亲自运行 → 把真实结果反馈给 AI → 追问 → 显式检查风险 → 形成可复用结论`。
- DeepSeek Harness 不只是聊天窗口，它能读写仓库、执行 Python、搜索资料、拆子任务、长期追踪一个目标，适合直接当作“数据分析协作工作台”来教学。

## 8 周课程地图

| 周 | 主题 | 主案例 | DSH 能力 | 交付物 |
|---|---|---|---|---|
| 1 | 从 Excel 到第一个数据问题 | 成绩单 | 读取文件、第一次 vibe loop | 1 个可运行 notebook |
| 2 | pandas 数据结构与读取 | 城市空气质量 | 让 DSH 读表、改代码、运行验证 | 数据概览卡片 |
| 3 | 数据清洗与审计 | 脏空气质量表 | 数据审计、清洗函数、修复报告 | 清洗报告 |
| 4 | EDA 与提出假设 | 银行营销数据 | 带着问题做 EDA、钻取追问 | 3 个发现 |
| 5 | 可视化表达 | 空气质量 + 银行营销 | 图表审查、调试、美化 | 1 张信息完整的面板 |
| 6 | 合并、分组与迷你项目 | 城市人口 + 空气数据 | 拆子任务、并行检查 | 迷你分析报告 |
| 7 | 第一个预测模型 | Titanic / 银行营销 | 防目标泄漏、模型验证 | 模型评估摘要 |
| 8 | 结课项目与展示 | 学生自选 | goal + subagent + workflow | 完整报告 + 3 分钟展示 |

## 需要准备的软件

- Python 3.10+，推荐 Anaconda 或官方 Python + Jupyter
- `pip install -r requirements.txt`（包含 pandas / numpy / matplotlib / seaborn / scikit-learn / openpyxl）
- DeepSeek Harness Web GUI（课程默认环境为 `http://127.0.0.1:3080`）
- 课程开始前把本仓库作为 DSH 的 workspace

## 教师上课建议

1. 每节课前 10 分钟演示一个“提示词 → DSH 运行 → 结果检查”的最小循环。
2. 学生练习时不允许只“复制最终代码”，必须保留报错、修改和追问记录。
3. 每周的作业都包含两个层次：完成分析 + 写一句“我验证了什么、还有哪些不确定”。
4. 第 8 周把学生分成 3 人小组，一人负责问题与口径，一人负责代码与验证，一人负责结论与展示，展示时轮换角色。
