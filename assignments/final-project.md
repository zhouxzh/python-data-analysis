# 结课项目说明

## 目标

独立完成一个“从问题到报告”的 Python 数据分析项目，并使用 DeepSeek Harness 作为协作工具。项目必须可复现，且每个结论都能从数据或代码中找到依据。

## 时间

- Week 8 第 1 节：确定题目、数据、口径、验收标准。
- Week 8 第 2 节：执行、验证、报告。
- Week 8 第 3 节：展示与互评。
- 课后按老师要求提交最终文件。

## 选题

优先从下面选择：

1. 纽约 Airbnb 价格：不同行政区/房型的定价差异有多大？价格能否被挂牌信息预测？
2. 纽约 Airbnb 供给画像：高价房源的共同特征是什么？评论和可订天数如何影响价格？
3. 城市空气质量：哪些区域的人均污染强度更高？
4. 银行营销：哪类客户更容易订阅定期存款？
5. Titanic：哪些特征与生还率相关，模型能否用于“事前”判断？
6. 自选：校园打卡、课程数据、公开开放数据。

自选题必须满足：数据来源明确、字段口径清楚、能在 8 周内完成。

## 数据要求

- 优先使用本仓库 `data/` 中的文件，主数据集为 `data/nyc_airbnb.csv`。
- 若自选数据，必须说明来源、许可和下载/收集时间。
- 原始数据放在 `raw/`，不修改。
- 所有清洗、分析、图表输出放在 `output/`。

## 目录要求

```text
projects/<姓名>/final/
  README.md
  raw/           原始数据（可复制，不改动）
  scripts/       清洗、EDA、可视化、模型代码
  output/        图表、CSV、HTML
  report.md      最终报告
  prompts.md     DSH 提示词与迭代记录（加分项）
```

## 必交内容

- 可运行的 `scripts/`，最好一键运行。
- 至少 1 张核心图 + 1 张汇总表。
- `report.md`，结构见下。

## report.md 结构

```markdown
# 题目

## 1. 摘要
用 2-3 句说清：分析什么、得到什么、还有什么不确定。

## 2. 数据来源与字段说明
来源、行数、字段含义、口径。

## 3. 清洗与口径
列出清洗动作和理由；说明缺失、重复、类型问题怎么处理。

## 4. 关键发现
每条发现包含：字段、计算方法、样本量、结果。

## 5. 局限与待验证假设
明确哪些是已验证事实、哪些只是推断。

## 6. 数据伦理声明
隐私、来源、是否避免误导。

## 7. 附录
DSH 提示词、迭代记录、复现说明。
```

## DSH 协作建议

- 用 plan mode 先定方案。
- 用 goal 追踪“清洗 → EDA → 可视化 → 报告”进度。
- 独立任务可用 subagent 或 workflow，但每个子任务完成后必须人工验收。
- 不要直接信任 AI 写的结论；要求 DSH 给出依据。
