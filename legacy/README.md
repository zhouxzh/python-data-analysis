# legacy：旧版教程与历史材料

本目录保存不再进入教学主线、但仍有参考价值的旧材料，不参与 VuePress 课程页面。

| 目录/文件 | 内容 |
|---|---|
| `Day01_intro.py` ... `Day09_Vibe_programing.py` | 旧版 Python 教程，已从 notebook 转成普通 `.py` |
| `pandas-course/` | 旧版 pandas 独立小课程 |
| `gld-example/` | GLD 金融数据旧案例 |
| `titanic-report/` | 完整 Titanic 分析报告 |
| `analysis.py` | 早期空气质量数据生成与分析脚本 |

运行旧教程脚本：

```bash
python legacy/Day01_intro.py
```

新版 8 周课程以根目录的 `第01周-*.md` 到 `第08周-*.md` 为主，配套内容在 `scripts/`、`prompts/`、`dsh/`、`examples/` 和 `assignments/`。
