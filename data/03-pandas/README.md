# 第 03 周数据：pandas 基础

第 03 周学习 DataFrame 读取、索引、筛选、排序、分组聚合。

## `olist_orders_45d.csv`

- 来源：GitHub `selva86/datasets`
- 规模：5,480 行 × 3 列
- 领域：电商
- 主要字段：`purchase_time`、`purchase_date`、`quantity`
- 课堂用法：日期解析、时间维度和订单数量分组。

## `College.csv`

- 来源：GitHub `selva86/datasets`
- 规模：777 行 × 18 列
- 领域：教育
- 主要字段：`Private`、`Apps`、`Accept`、`Enroll`、`Outstate`、`Grad.Rate`、`S.F.Ratio`
- 课堂用法：筛选公立/私立学校，按指标排序和分组汇总。

## `Cars93.csv`

- 来源：GitHub `selva86/datasets`
- 规模：93 行 × 27 列
- 领域：汽车
- 主要字段：`Manufacturer`、`Type`、`Price`、`MPG.city`、`MPG.highway`、`Horsepower`、`Weight`
- 课堂用法：练习选择列、条件筛选、排序以及按品牌/类型分组。
