# 第 08 周数据：结课项目与展示

第 08 周不新增主数据集，学生从前 7 周数据中选择一个项目主题，也可以重新组合多张表。

推荐选题：

- Airbnb 价格与房源供给：`data/01-agent/nyc_airbnb.csv`
- 零售销售或电商订单分析：`data/02-python/supermarket_sales.csv`、`data/03-pandas/olist_orders_45d.csv`
- 电信客户流失清洗与分析：`data/04-cleaning/telco_customer_churn.csv`
- 钻石价格 EDA 与可视化：`data/05-eda-viz/diamonds.csv`
- 汽车销量合并与对比：`data/06-merge/norway_new_car_sales_by_make.csv`、`data/06-merge/norway_new_car_sales_by_model.csv`
- 信贷、房价或银行流失预测：`data/07-modeling/` 下三个数据集
- 参考项目：`data/08-final/penguins.csv`，用于演示数据审计、分组汇总和结论复盘。
