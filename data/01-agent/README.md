# 第 01 周数据：纽约 Airbnb

## `nyc_airbnb.csv`

- 来源：HuggingFace `gradio/NYC-Airbnb-Open-Data`，原始文件 `AB_NYC_2019.csv`
- 镜像下载：`https://hf-mirror.com/datasets/gradio/NYC-Airbnb-Open-Data/resolve/main/AB_NYC_2019.csv`
- 许可：AFL-3.0
- 规模：48,895 行 × 16 列，约 7MB
- 主要字段：`neighbourhood_group`、`room_type`、`price`、`minimum_nights`、`number_of_reviews`、`availability_365` 等
- 用途：第 01 周第 3 节做第一次数据读取和简单描述，看到真实表格、真实缺失和真实异常值。
