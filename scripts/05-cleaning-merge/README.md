# scripts/05-cleaning-merge

Week 5 数据清洗、合并与分组聚合，只使用 pandas。每个文件对应 `05-数据清洗与分组聚合.md` 中的一个代码块，按出现顺序排列。

| 文件 | 教程位置 | 用途 |
|---|---|---|
| `01-cars93-audit.py` | 1.3 | Cars93_miss 缺失、重复和类型错误最小审计 |
| `02-cars93-missing-report.py` | 1.5 | 完整报告每列缺失数和 dropna 影响 |
| `03-telco-churn-rate.py` | 2.3 | 按 Contract 计算流失率最小代码 |
| `04-telco-churn-audit.py` | 2.5 | 完整审计电信客户缺失和流失率 |
| `05-norway-merge-demo.py` | 3.3 | 演示不 strip 和 strip 后的合并差异 |
| `06-norway-merge-report.py` | 3.5 | 清洗品牌名并对比两张汽车销售表 |
| `07-market-arrivals.py` | 3.5 | groupby 和 pivot_table 汇总到货数据 |
