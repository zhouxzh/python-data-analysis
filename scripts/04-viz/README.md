# scripts/04-viz

Week 4 数据可视化，只使用 pandas 和 matplotlib。每个文件对应 `04-数据可视化.md` 中的一个代码块，按出现顺序排列。

| 文件 | 教程位置 | 用途 |
|---|---|---|
| `01-diamonds-histogram.py` | 1.3 | 钻石价格直方图 |
| `02-diamonds-boxplot.py` | 1.3 | 钻石价格箱线图 |
| `03-midwest-bar.py` | 1.3 | 各州人口柱状图 |
| `04-diamonds-summary.py` | 1.5 | 钻石价格和 cut 样本统计 |
| `05-diamonds-save-figures.py` | 1.5 | 保存钻石直方图和按 cut 箱线图 |
| `06-midwest-summary.py` | 1.5 | 各州人口和县数量统计 |
| `07-midwest-save-figure.py` | 1.5 | 保存各州人口柱状图 |
| `08-energy-daily-line.py` | 2.3 | 能源日均负荷折线图 |
| `09-energy-parse-summary.py` | 2.5 | 解析时间并按天聚合摘要 |
| `10-energy-save-figure.py` | 2.5 | 保存最近 120 天负荷折线图 |
| `11-life-year-line.py` | 3.3 | 预期寿命年度均值折线图 |
| `12-life-status-lines.py` | 3.3 | 按 Status 分组趋势线 |
| `13-life-subplots.py` | 3.3 | 两个子图展示两种趋势 |
| `14-life-summary.py` | 3.5 | 预期寿命年份和 Status 样本统计 |
| `15-life-save-combined.py` | 3.5 | 保存预期寿命组合图 |
