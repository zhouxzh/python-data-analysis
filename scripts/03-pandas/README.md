# scripts/03-pandas

对应 `data/03-pandas/`，开始使用 pandas。每个文件对应 `03-pandas基础.md` 中的一个代码块，按出现顺序排列。

| 文件 | 教程位置 | 用途 |
|---|---|---|
| `01-read-orders-structure.py` | 1.3 | 读取订单表并查看 shape、columns、dtypes |
| `02-orders-head-describe-info.py` | 1.5 | 查看订单表头尾、describe 和 info |
| `03-orders-parse-dates.py` | 1.5 | 解析 purchase_time 和 purchase_date |
| `04-college-loc-iloc.py` | 2.3 | 用 loc 和 iloc 取数 |
| `05-college-filter.py` | 2.5 | 按 Private 和 Apps 条件筛选 |
| `06-college-sort-new-columns.py` | 2.5 | 排序并新建 AcceptRate、TotalCost |
| `07-cars-value-counts-groupby.py` | 3.3 | 查看 Type 分布并按车型汇总价格 |
| `08-cars-origin-type-mean.py` | 3.5 | 查看产地、品牌分布和车型均值 |
| `09-cars-agg-summary.py` | 3.5 | 按车型聚合多个统计量并排序 |
| `10-cars-missing.py` | 3.5 | 报告 Cars93 中的缺失列 |
